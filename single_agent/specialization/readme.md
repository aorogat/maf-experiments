## Volkert
The dataset used in this experiment is a CSV version of the Volkert dataset originally punlished by OpenML.  
[VolkertOpenML](https://www.openml.org/search?type=data&status=active&id=41166&sort=runs)


## Yelp
For the experiment a merged CSV file was used from the version of the Yelp dataset published by Yelp Open dataset. The file was created by merging 4 data files (Business.csv, Checkins.csv, Reviews.csv, Users,csv) from the original dataset.     
[YelpOpenDataset](https://business.yelp.com/data/resources/open-dataset/)
